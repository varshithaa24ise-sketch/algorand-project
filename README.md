# Algorand Project

## About

This project is developed as part of the Algorand course. It focuses on building and testing an application using the Algorand blockchain.

## Project Goals

* Learn Algorand blockchain development
* Work with Algorand SDKs and APIs
* Develop and test blockchain functionality
* Build and maintain the project throughout the course

## Technologies

* Algorand
* Algorand SDK
* GitHub
